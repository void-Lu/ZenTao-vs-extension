# 附件上传时间列 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在禅道 VS Code 扩展的详情页附件表和 Markdown 导出附件表中显示附件“添加时间”。

**Architecture:** 复用现有 `AttachmentViewModel.addedDate`，只补齐最终渲染层与导出层。`src/html.ts` 负责 Webview 附件表 HTML，`src/markdownExport.ts` 负责导出 Markdown 附件表；不改 API、详情映射、下载、预览和 Webview 消息流。

**Tech Stack:** TypeScript、VS Code Webview HTML、Vitest、npm scripts、现有 `sanitize-html`/HTML 转义工具链。

- [ ] **Step 3: 实现详情页 HTML 列**

```ts
const attachments = detail.attachments.length
```

### Task 2: Markdown 导出附件表显示“添加时间”

**Files:**
- Modify: `src/markdownExport.test.ts`

- [ ] **Step 1: 写失败测试**

在 `src/markdownExport.test.ts` 的 `converts the rendered detail content to markdown without raw response data` 用例中，保留 `detail()` 中现有附件数据：

```ts
attachments: [{ id: 1, name: 'spec.docx', size: '15K', addedDate: '2026-05-25', url: 'https://zentao.example.com/file/1', raw: {} }],
```

将当前附件行断言：

```ts
expect(markdown).toContain('| [spec.docx](https://zentao.example.com/file/1) | 15K |');
```

替换为两个断言：

```ts
expect(markdown).toContain('| 文件名 | 大小 | 添加时间 |');
expect(markdown).toContain('| [spec.docx](https://zentao.example.com/file/1) | 15K | 2026-05-25 |');
```

- [ ] **Step 2: 运行测试确认失败**

Run:

```powershell
npx vitest run src/markdownExport.test.ts -t "converts the rendered detail content to markdown without raw response data"
```

Expected: FAIL，失败点包含 `expected ... to contain '| 文件名 | 大小 | 添加时间 |'` 或 `expected ... to contain '| [spec.docx](https://zentao.example.com/file/1) | 15K | 2026-05-25 |'`。

- [ ] **Step 3: 实现 Markdown 附件表列**

在 `src/markdownExport.ts` 的 `detailToMarkdown()` 附件导出分支中，将当前逻辑：

```ts
lines.push('| 文件名 | 大小 |', '| --- | --- |');
for (const attachment of detail.attachments) {
  lines.push(`| ${attachmentName(attachment)} | ${escapeTableCell(attachment.size || '暂无')} |`);
}
```

替换为：

```ts
lines.push('| 文件名 | 大小 | 添加时间 |', '| --- | --- | --- |');
for (const attachment of detail.attachments) {
  lines.push(`| ${attachmentName(attachment)} | ${escapeTableCell(attachment.size || '暂无')} | ${escapeTableCell(attachment.addedDate || '未知')} |`);
}
```

实现要求：

- Markdown 表格不增加“预览”列。
- 添加时间使用 `escapeTableCell()`，避免竖线或换行破坏表格。
- 无附件分支仍输出 `暂无附件`。
- 不把 `detail.raw` 写入 Markdown。
